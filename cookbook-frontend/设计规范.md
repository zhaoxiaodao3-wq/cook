# “小圈子菜谱共享平台”设计规范文档 (Design System Guide)

## 1. 设计理念 (Design Philosophy)

* **核心关键词**：清新、温馨、私密、健康。
* **设计目标**：通过自然的绿色调和通透的排版，营造一个适合家人朋友分享烹饪乐趣的私密空间。强调“家常感”与“易用性”，通过大圆角和柔和阴影降低视觉压力。

---

## 2. 色彩规范 (Color Palette)

### A. 品牌色 (Brand Colors)

| 角色 | 色值 (HEX) | 使用场景 |
| :--- | :--- | :--- |
| **主品牌色 (Primary)** | `#52C41A` | 核心按钮、激活状态、状态标签、星级评分、品牌标识。 |
| **品牌浅色 (Primary Container)** | `#F6FFED` | 按钮浅色背景、成功提示背景。 |

### B. 中性色 (Neutral Colors)

| 角色 | 色值 (HEX) | 使用场景 |
| :--- | :--- | :--- |
| **背景色 (Surface)** | `#FBF8FD` | 页面整体背景，带有一丝暖调，增加温馨感。 |
| **容器背景 (Surface Bright)** | `#FFFFFF` | 卡片背景、列表容器、弹窗内容。 |
| **主标题文字 (On-Surface)** | `#1A1A1A` | 菜名、主要标题、重要信息。 |
| **次要文字 (Secondary Text)** | `#8C8C8C` | 时间戳、副标题、说明文字、未选中状态。 |
| **分隔线/边框 (Outline)** | `#F0F0F0` | 卡片描边、列表分割线、搜索框边框。 |

---

## 3. 字体系统 (Typography)

* **主字体**: `Plus Jakarta Sans` (英文/数字) / 系统默认黑体 (中文)。
* **字阶定义**:
  * **Display/Heading**: 24px - 32px (用于大标题、首页品牌名)
  * **Title**: 18px - 20px (用于页面顶部标题、卡片标题)
  * **Body**: 14px - 16px (用于正文内容、制作步骤)
  * **Label/Caption**: 12px (用于辅助说明、底部导航文字)

---

## 4. 视觉规范 (Visual Metrics)

* **圆角规范 (Border Radius)**:
  * **通用卡片/按钮**: `16rpx (8px)` - 营造圆润亲切的触感。
  * **全圆角**: 用于搜索框、浮动按钮 (FAB)。
* **阴影规范 (Shadows)**:
  * **轻量阴影**: `0 4px 12px rgba(0,0,0,0.04)` - 用于首页卡片，增强悬浮感。
  * **导航栏阴影**: `0 -4px 20px rgba(38,109,0,0.04)` - 用于底部固定栏，突出层级。
* **间距规范 (Spacing)**:
  * **页面外边距 (Margin)**: `32rpx (16px)`。
  * **卡片内边距 (Padding)**: `24rpx (12px)`。
  * **模块间距 (Gap)**: `16px / 24px`。

---

## 5. 核心组件规范 (Core Components)

### A. 导航系统 (Navigation)

* **TopAppBar**: 居中对齐/左对齐标题，右侧常用功能入口（搜索/通知）。
* **BottomNavBar**: 4-Tab 结构（首页、全部菜品、上传、个人中心）。
  * **中心按钮**: “上传”采用全背景色填充的圆形按钮设计。

### B. 交互卡片 (Cards)

* **菜谱卡片**: 采用大图背景 + 底部内容叠加设计，信息包含：菜名、作者头像、评分。
* **列表卡片**: 左图右文或上图下文，带状态标签（如：川菜、健康、已回复）。

---

## 6. 开发还原建议 (UniApp + Vue3)

* **样式库**: 建议使用 `Tailwind CSS` 配合自定义配置文件。
* **单位**: 建议使用 `rpx` 以适配微信小程序的多端屏幕。
* **动画**:
  * 点击态：`active:scale-95 transition-transform`。
  * 页面切换：`fade-in-up` 向上渐显动画。
