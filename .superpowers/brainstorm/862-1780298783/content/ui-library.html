Taro React 小程序 UI 库选型

React 代码已有 1200+ 行，现在选 UI 组件库来替代 Tailwind + Lucide

A

NutUI + SCSS Modules

京东出品，专为移动端设计，组件覆盖率高（卡片、评分、导航栏、表单等），与 Taro 深度集成。SCSS 变量对齐 Design Tokens。

B

Taro UI + SCSS Modules

社区最成熟，中文文档好，组件全面。但更新较慢，部分组件样式偏老旧。

C

纯手写组件 + SCSS Modules

完全自定义，与设计稿 1:1 对齐。但按钮、输入框、弹窗、星级评分、标签等都要从零写，工期最长。

分析维度

NutUI 优势

  • 移动端原生体感最好
  • Steps/Stepper 组件直接匹配制作步骤需求
  • Rate 星级评分内置
  • 京东持续维护，React 版本活跃

NutUI 劣势

  • NutUI 4.x 需 React 18（当前代码 React 19）可能有兼容问题
  • 默认主题色需全局覆盖
  • 社区案例少于 Taro UI

推荐 A — NutUI 更匹配菜谱小程序的移动端交互需求
